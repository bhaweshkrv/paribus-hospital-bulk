    Import hospitals

    Upload a CSV with up to 20 hospitals. The whole file is checked first, so a bad file never creates anything.

    Columns: name address phone (phone is optional)

    What happens when you import

    1. Check

      Every row is validated. Problems are listed before anything is sent.

    2. Create

      All hospitals are created at once, hidden, in a single batch.

    3. Go live

      Once every hospital exists, the whole batch is activated together.

    If a hospital can't be created, the batch stays hidden. You can retry the failures or roll the batch back.
